# 发布说明

- 支压指标新增“支压类型”三选一配置：常规显示结构化支撑压力，波段显示最近确认摆动点至当前的趋势段高低，撑压只显示当前价格附近最近的支撑与压力；三种类型互斥，配置保存于本机。
- 判断栏新增「日内均价」和「DXY 对照」因子。日内均价在有成交量的品种上使用典型价格加权；黄金没有统一现货成交量时使用日内典型价格均值作为代理，并要求价格位置与均价方向一致才给方向票。
- DXY 对照只在黄金与美元指数呈反向运行时提供辅助方向票；黄金与 DXY 同向或变化过小时保持中性，避免把历史相关性当成硬规则。
- 主图指标菜单支持显示日内均价线，悬停提示包含对应读数；REST 与 WebSocket K 线保留成交量字段，为有成交量品种提供加权计算基础。
- 左侧因子按动量、结构、触位收回、位置和宏观对照分族汇总，宏观对照权重低于结构因子。美国实际利率、国债收益率、ETF流向和CFTC持仓仍需外部数据源，未用黄金价格或DXY伪造。
- 基线快照已按新增因子重新录制，项目测试套件通过。

### 2026-08-28

- 指标下拉新增「超级趋势」：`src/indicators/supertrend.js`，Wilder ATR 包络的趋势跟踪线。以 `(最高+最低)/2 ± 倍数×ATR` 建上下轨，多头段只抬下轨、空头段只压上轨，收盘穿越上一根轨道才换向；多头段线画在价格下方为涨色，空头段画在上方为跌色，换向处标「转多」「转空」。专属设置栏可调 ATR 周期（7 / 10 / 14）与倍数（2 / 2.5 / 3），右侧读数给出当前方向、翻转位、距现价距离与本段已走根数。指标滞后于反转，震荡里会来回换向，只描述趋势方向，不是下单指令。
- 指标下拉新增「箱体震荡」：`src/indicators/box.js`，摆动高低点（k=2 分形）按 ATR 容差聚类出横向箱体，上下沿各需两次以上触碰、箱体高度需落在 1.1–5 倍 ATR 之间，否则判为箱体未现，避免在单边行情里硬框区间。箱体起点自摆动点向左扩展到仍留在区间内的最后一根 K。画上下沿、中轴虚线、半透明箱体与触碰点，状态条给出高度（含 ATR 倍数）、上下沿触碰次数和现价在箱体中的位置；收盘越过边缘 `max(0.4 ATR, 6% 箱高)` 才记上破或下破，破位起点取当前连续留在边缘之外的第一根。回看根数可选 60 / 120 / 180。
- 两个新指标的翻转与破位事件并入时间信号线；主图悬停提示补充超级趋势轨位与箱体区间；开关与参数写入本机 `localStorage`（`gold-minute-ind`）。
- 新增 `tests/trend-box.mjs`（已并入 `node tests/run-all.mjs`）：超级趋势按 period=2 / mult=1 全程手算逐值核对（含平滑规则、翻转点、up/dn 分段），并断言同方向段内跟踪线不回撤、倍数越大换向不更多；箱体覆盖识别、上下破位起点、单边不误报与回看根数生效，同时验证两者的缓存键包含各自参数。
