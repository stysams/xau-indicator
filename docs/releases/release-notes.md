# 发布说明

### 2026-08-27

- 按 `docs/optimization-backlog.md` 落地 A1–A22 与 B1–B9：纸面开平仓按 bid/ask 取价并扣一次往返点差；订单块按中位回补；高空低多去掉前视并修复 forming；判断改为已收盘 K + 分族加权（阈值 0.35）；头肩与 SMC 收紧噪声门槛；BOLL 动态轨不再并入静态支压打分；带宽分位随周期；近 25 分钟结果明确为复盘而非回测。
- 新增可入库验证套件 `tests/`（`node tests/run-all.mjs`）：指标数学断言、随机漫步基准、样本外种子对照。本机套件全部通过；头肩噪声命中约 0.2（收紧前约 0.66–0.82）。
- `computeHkldChart` 复用 `hkldPrep`，去掉重复的五段助手逻辑（A21）。

- 支压指标参考 Gate 撑压线公开口径优化：BOLL20 上下轨与中轨保留为动态区域参照（`bands`），与摆动高低点、整数位、今开和昨收分开处理，避免移动轨道与静态位共用触碰计数。
- 支压位改为按 ATR 容差显示价格区域，强度同时考虑触碰次数、距现价远近和近期性；最多保留 5 条支撑与 5 条压力。
- 收盘越过 ATR 阈值才确认破位，保留破位后的支撑压力角色互换提示，减少单根影线造成的误判。

- 模拟交易弹窗支持独立启停自动开单。关闭后仍可观察开单信号，已有纸面持仓继续按原计划管理。
- 自动开单可设置止盈 ATR 倍数、止损 ATR 倍数、最长持仓时间和开单冷却时间，设置按品种保存在本机并从下一笔新单生效；TP/SL 地板随 ATR/tick 调整，黄金常态下倍数滑杆可生效。
- “判断多空”可读取当前页面已加载的全部K线，展示分族加权结果与判断依据，并同步选择做多或做空方向。
- 弹窗信息结构和窄屏布局经过调整，参数、方向判断和订单记录在桌面及手机宽度下保持清晰可用。
